# Heritage Journeys Redesigned

Redesign the complete Derivative Bharat website:

Current website:
https://derivative-bharat-five.vercel.app/

UI/UX reference:
https://www.thomascook.in/

GOAL

Completely redesign Derivative Bharat into a clean, premium, simple, highly professional travel and heritage-tour website inspired by the overall UI structure and usability of Thomas Cook India.

IMPORTANT:
Do NOT directly clone Thomas Cook's branding, logo, copyrighted graphics, exact text, or exact page design.

Use Thomas Cook only as inspiration for:

Layout hierarchy

Navigation simplicity

Tour/package card structure

Search experience

White-space usage

Horizontal carousels

CTA placement

Section spacing

Destination presentation

Booking-focused UX

Derivative Bharat must retain its own heritage-focused personality and branding.

ANIMATION RULES

Use animation carefully.

Allowed:

Fade-up on scroll

Small card hover lift

Image zoom 1.03–1.05

Subtle navbar transition

Carousel slide

Button arrow animation

Very subtle image parallax

Do NOT use:

Heavy 3D animations

Continuous background animations

Cursor-following effects

Large floating objects

Strong glowing borders

Excessive page transitions

The purpose of animation is to make the site feel polished, not experimental.
